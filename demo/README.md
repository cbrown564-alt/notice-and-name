# Notice & Name browser preview

This is a static, public-safe preview of the approved `non-concordance` concept. It is deliberately smaller than the iOS app: there is no account, persistence, analytics, free-form input, or network-backed behavior.

## Preview locally

From the repository root, run a static server so the relative font path works:

```bash
npx serve demo
```

Then open the local URL shown by the server. A plain file URL may work in some browsers, but the static server is the reliable path.

## What is represented

- The copy, concept definition, partner-safe phrase, and citation labels are from the approved `non-concordance` entry in `content/v2/bundles/v2-full.bundle.json`.
- The two-track interaction follows the native `NonConcordanceDiagramView`: body response and felt desire begin aligned, can be moved independently, and reveal “They can diverge” after a meaningful separation.
- The browser version uses native range controls for keyboard, touch, and pointer access. It is an educational preview, not a web port of the SwiftUI app.
- The reduced-motion stylesheet removes decorative motion and keeps the teaching frame available.

## Review boundary

The exhibit is intended for adults and contains educational sexual-health language without explicit imagery. It says that nothing is saved. The “Recorded preview coming next” handoff is intentionally non-functional until the native walkthrough exists.
